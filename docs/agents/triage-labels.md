# 议题分流标签

工程技能使用五种标准分流角色。本文件将这些角色映射到本仓库议题跟踪系统中的实际标签名称。

| 技能中的标准角色  | 本仓库标签        | 含义                         |
| ----------------- | ----------------- | ---------------------------- |
| `needs-triage`    | `needs-triage`    | 等待维护者评估               |
| `needs-info`      | `needs-info`      | 等待报告者补充信息           |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由智能体独立处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现                 |
| `wontfix`         | `wontfix`         | 不会处理                     |

当技能提到某个分流角色时，应使用表格中对应的仓库标签名称。

如需适配仓库已有的标签体系，只修改“本仓库标签”列，不要修改“技能中的标准角色”列。
