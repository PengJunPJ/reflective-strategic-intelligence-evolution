# 公开合规的高对抗场景设计依据

> 对应 Issue #10。研究截止日期：2026-11-01。
> 范围：仅使用公开、非敏感的仿真环境文档与试验设计指南；不采集真实装备性能、部署、作战计划或非公开数据。

## 结论

建议优先采用“**诱饵与真实目标混合 + 局部观测 + 临时通道变化 + 异构资源约束**”的抽象红蓝对抗场景。这不是对基准毁伤概率矩阵的单纯缩放：智能体还必须判断信息可信性、保留稀缺资源并在可达性变化后重规划。每个机制都可以在纯合成、无量纲的数据上实现。

关键设计原则是：

1. 把环境改变作为可控因子，不把它混入无法解释的随机噪声。
2. 保持任务可解：变化后至少存在一个满足全部硬约束的方案。
3. 只引用一手来源证明“这类抽象机制有成熟范式”；所有数值明确标为“竞赛设计假设”，不宣称其对应真实装备。

## 一手来源与可支持的主张

### S1. MPE2 `simple_adversary`：隐藏目标与诱骗

- 来源：Farama Foundation，[MPE2 Simple Adversary 官方环境文档](https://mpe2.farama.org/environments/simple_adversary/)。
- 来源等级：环境维护者的官方文档。
- 可支持：对手不知道哪个地标是真实目标；友方需要分散覆盖地标以迷惑对手。文档还提供按最近邻居限制观测的部分可观测参数。
- 不可支持：不能由此推导真实作战的诱饵配比、识别概率或传感器距离。
- 可用方式：将“真/伪目标身份”作为隐变量，观测仅给出带置信度的类别。

### S2. MPE2 `simple_tag`：异构机动与障碍

- 来源：Farama Foundation，[MPE2 Simple Tag 官方环境文档](https://mpe2.farama.org/environments/simple_tag/)。
- 来源等级：环境维护者的官方文档。
- 可支持：环境明确区分速度不同的两类智能体，并设置会阻挡通行的障碍物；也支持限制可观测邻居数。
- 不可支持：不能把文档中归一化坐标、碰撞奖励或默认智能体数量当作现实参数。
- 可用方式：以“达到成本/时延”而不是真实速度建模异构性；以有向可达图表示障碍和通道。

### S3. MPE2 `simple_push`：拒止与对手改变可达性

- 来源：Farama Foundation，[MPE2 Simple Push 官方环境文档](https://mpe2.farama.org/environments/simple_push/)。
- 来源等级：环境维护者的官方文档。
- 可支持：对手的目标包含让友方远离任务地标，表明“不只改变价值，还干扰对方完成任务的能力”是成熟对抗抽象。
- 不可支持：不支持任何具体干扰手段或现实装备效果。
- 可用方式：将其抽象为对手在特定时刻关闭/打开若干可达边，不描述实现拒止的物理机理。

### S4. MPE2 `simple_crypto` 与 `simple_reference`：信息不对称

- 来源：Farama Foundation，[MPE2 Simple Crypto](https://mpe2.farama.org/environments/simple_crypto/) 和 [MPE2 Simple Reference](https://mpe2.farama.org/environments/simple_reference/) 官方环境文档。
- 来源等级：环境维护者的官方文档。
- 可支持：`simple_crypto` 中敌对方可观测公共通信但不知私有信息；`simple_reference` 中一方的任务目标由另一方知道，需通信协作。
- 不可支持：不能把这些环境当作现实通信保密性或抗干扰性的证据。
- 可用方式：将情报延迟、丢失与置信度作为纯数据层的仿真因子。

### S5. NIST/SEMATECH 试验设计指南：用因子试验而非随意调参

- 来源：美国国家标准与技术研究院（NIST），[Engineering Statistics Handbook: Choosing an experimental design](https://www.itl.nist.gov/div898/handbook/pri/section3/pri3.htm)。
- 来源等级：政府计量科学机构的官方指南。
- 可支持：应根据目标、因子数、资源与所需精度选择试验设计；多因子试验能研究主效应和交互效应。
- 不可支持：NIST 不为本竞赛的任何场景参数背书。
- 可用方式：预先固定因子与水平，用配对种子比较 `norethink`/`rethink`，报告主效应和交互效应。

## 候选场景方向

| 方向 | 场景变化 | 迫使智能体改变什么 | 区别于基准简单变体 | 一手范式依据 |
|---|---|---|---|---|
| A. 诱饵识别与资源保留 | 部分目标的真/伪置信度在中途更新 | 从立即追求期望价值改为保留资源、信息确认或分散覆盖 | 变化的是信念状态和决策时序，不只是概率矩阵 | S1 |
| B. 动态通道与异构窗口 | 可达图的若干边在预先公开的时刻关闭/恢复 | 重新分配快/慢、高/低容量资源，避免过期可行解 | 引入时序可达性与硬约束 | S2、S3 |
| C. 局部观测与延迟情报 | 只返回最近 `k` 个目标或延迟一轮的状态摘要 | 评估旧情报风险，选择稳健分配或信息获取 | 输入本身不再是完全可观测的静态矩阵 | S1、S2、S4 |
| D. 组合场景（推荐） | A+B+C 中每次只激活两类变化 | 需检索旧反思知识，识别当前变化类型后选择不同操作 | 验证知识适用域与交互效应，不是对单参数过拟合 | S1–S5 |

## 推荐的无量纲参数化

下表的数值全部是**竞赛设计假设**，是为了建立可复现的难度梯度，不是从现实装备测量得到的参数。

| 因子 | 水平 | 定义方式 | 安全与可复现说明 |
|---|---|---|---|
| 伪目标比例 `r_decoy` | 0 / 0.15 / 0.30 | 候选目标中伪目标的比例 | 纯合成标签 |
| 观测可见率 `q_obs` | 1.0 / 0.7 / 0.4 | 当轮能看到有效摘要的目标比例 | 独立于任何真实传感器 |
| 情报延迟 `d_info` | 0 / 1 / 2 轮 | 状态摘要落后的决策轮数 | 使用逻辑轮次，不使用真实通信时延 |
| 通道受限率 `r_block` | 0 / 0.10 / 0.25 | 可达图中临时不可用边的比例 | 开局生成连通图，变化后重验可行性 |
| 异构性 `h_cost` | 1.0 / 1.5 / 2.0 | 两类资源的归一化到达成本比 | 无量纲成本比，不是速度或射程 |
| 变化时刻 `t_change` | 25% / 50% / 75% | 决策时域的归一化位置 | 确保既有变化前基线，又留出足够适应窗口 |

不建议将全部水平做直积。先用小型筛选试验识别有效因子，再对关键交互（例如 `r_decoy × q_obs`、`r_block × h_cost`）做预注册的配对比较。

## 场景生成与平衡性规则

1. **先生成、后验证**：场景生成后运行一次可行性检查；无可行解则按种子重生成，不在运行中偷改约束。
2. **保持预算对称**：`norethink` 和 `rethink` 使用同一输入、随机种子、总时限和计算资源；反思消耗必须计入总预算。
3. **保持红蓝可能性**：防止一个策略在所有水平上必胜；至少要有“立即分配”与“保留/重规划”各自占优的区域。
4. **变化不使任务偷换**：总目标与评分函数保持不变，只变更观测、可达性或资源状态。
5. **保留决策证据**：记录变化信号、检索到的反思知识、修改的策略/参数、方案差异和最终收益。

## 能否真正暴露适应能力

推荐至少设置四个评测分区：

- **ID-静态**：训练/调参分布内且无场景变化，检查强基线质量。
- **ID-变化**：已见过的变化类型，但采用未见种子，检查稳定性。
- **OOD-强度**：变化类型不变，但强度落在调参区间外，检查参数外推。
- **OOD-组合**：单独见过 A/B/C，测试时组合两类变化，检查反思知识的组合与冲突消解。

主指标不应只有总得分，还应包括：变化后遗憾、恢复到预定质量阈值所需轮数、硬约束违反数、反思开销、以及配对种子上 `rethink - norethink` 的改善分布。若 `rethink` 仅多用计算时间而没有改变决策行为，不应计为反思收益。

## 合规红线与引用表述

- 文档中使用“资源”、“候选目标”、“可达边”、“归一化成本”等抽象词，不给出真实装备名称、性能和地理信息。
- 所有合成数据集保存生成器版本、种子、无量纲参数和可行性检查结果。
- 可以写“参考 MPE2 官方环境中的信息不对称/障碍/对抗奖励范式”；不应写“MPE2 证明该参数符合真实作战”。
- 如后续需要真实尺度参数，必须另立合规审查；对本初赛场景而言没有这个必要。

## 局限与待确认事项

1. MPE2 是通用多智能体环境，只支持场景机制的抽象合理性，不支持任何真实作战结论。
2. 最终字段、分配容量、目标函数和反思轮次上限仍待官方材料确认；本文的参数化应作为上层场景生成规范，不预设最终 JSON Schema。
3. 高对抗性不等于不可解或高随机性。如预试验显示两种智能体都无法稳定超过随机策略，应先降低因子强度，而不是将失败归因于“场景更真实”。
