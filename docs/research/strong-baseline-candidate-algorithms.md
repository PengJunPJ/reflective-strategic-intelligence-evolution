# 目标分配强基线候选算法研究

> 对应议题：#2。研究日期：2026-11-01。
> 边界：只研究抽象组合优化问题与公开算法，不涉及真实武器参数或作战部署。

## 结论

建议将强基线定为“**贪心构造 + 局部搜索 + 有时限的精确/下界求解**”三层结构，而不是单独的遗传算法或让大模型直接分配。

1. **必达层**：用“当前边际期望损失降低”构造可行解，之后作 1-重定向、2-交换和小邻域再优化。这一层实现简单、任意时刻都有可行解，适合 `200×500` 和降级路径。
2. **质量层**：实现 Ahuja 等人的网络流构造与大规模邻域（VLSN）思路，或以“固定大部分分配，对小邻域做 MILP/CP-SAT 精确再优化”落地。该文报告在数秒内对最高 `200×200` 的实例得到几乎最优解，是与本题尺度最接近的公开直接证据 [S1]。
3. **证据层**：对 `20×50` 使用严格时限的分支定界/MILP，获得最优值或可证明下界；对 `200×500` 只将精确求解器用于小邻域或下界，不应把全局最优证明放在主时限内。

最终技术选型仍需等官方确认目标函数、每个决策单元的容量、每个目标的上下限、可达性/兼容性约束和运行环境。在这些字段发布前，不应声称已完成性能选型。

## 研究使用的抽象

经典静态模型令 `x_ij` 表示决策单元 `i` 是否分配给目标 `j`，`p_ij` 是成功概率，`v_j` 是目标价值。在各次作用条件独立的标准假设下，最小化作用后期望剩余价值：

```text
min  Σ_j v_j ∏_i (1 - p_ij) ^ x_ij
s.t. Σ_j x_ij ≤ capacity_i, x_ij ∈ {0, 1}
```

Ahuja 等人将此类 WTA 定性为非线性整数规划和 NP-complete 问题 [S1]。因此，`200×500` 代表最多 100,000 个二元边变量，“变量数看起来不大”并不意味着非线性全局最优容易。

这个抽象只用于比较候选算法，不是对尚未公布的赛题模型作事实声明。

## 候选方案比较

|---|---|---|---|---|---|
| 边际收益贪心 | 不保证最优；目标损失降低为单调次模时，通用 matroid 贪心有 `1/2` 保证 [S2] | 数组实现约 `O(WT)` 至 `O(WT log(WT))` | 高，可确定性打破平局 | 很高；可调整价值、风险惩罚、冗余上限、打破平局规则 | 必达层和降级保底 |
| 1-重定向/2-交换局部搜索 | 单调改进到局部最优；无全局证明 | 可按评估次数或时间随时停止 | 高 | 高；邻域类型、候选表宽度、禁忌期和时间可调 | 默认质量增强 |
| 网络流构造 + VLSN | 有直接 WTA 文献；可与下界结合评估 gap [S1] | 文献报告 `200×200` 几乎最优解在数秒内 [S1] | 较高，但实现难度高于普通局邻域 | 高；网络流子问题可观测，邻域规则可控 | **首选强基线核心** |
| 全量 MILP/分支定界 | 在正确精确建模下可给最优性或 gap 证据 | 对约束稠密的模型可急剧变慢；一个公开干扰约束实验从无干扰的 0.1/2.4 秒增至 3/超 8 小时 [S3] | 取决于求解器与时限；需固定随机种子/线程 | 高；约束和 gap 清晰 | 小规模证明器、小邻域优化器 |
| 模拟退火/阈值接受 | 公开 WTA 实验报告标准 PC 上几秒可得大实例近似最优解 [S4] | 时间预算可控，但性能取决于温度表和邻域 | 中；需固定种子且多次运行 | 中高；温度、接受阈值可调，但因果解释弱于确定性局邻域 | 备用多样化器，不作唯一主线 |
| 遗传/群体智能 | 通常无最优性证明 | 需大量适应度评估，在严格时限下性价比不确定 | 中低 | 中；参数多，难把改进归因到一条经验 | 不建议作默认基线 |
| 线性和分配/匈牙利算法 | 一对一线性目标下精确 [S5] | 很快 | 高 | 高 | 只适用于每边一次线性收益且一对一；**不能直接替代多次作用的乘积目标** |

### 为什么贪心不应单独作为强基线

对已分配集合 `S`，把决策单元 `i` 再分给目标 `j` 的边际收益为：

```text
Δ(i, j | S) = v_j · p_ij · ∏_(k already assigned to j) (1 - p_kj)
```

它会自然体现边际收益递减，易于日志化和解释，但早期选择仍可能锁死后续组合。因此至少要加 1-重定向和 2-交换；时间允许时再用求解器精确优化一个小邻域。

### 为什么不选“全量 MILP 走到底”

HiGHS 和 SciPy 都支持 MILP，SciPy 接口明确暴露 `node_limit`、`time_limit`和 `mip_rel_gap`，所以它适合做可控时限的证明层 [S6][S7]。但经典期望剩余价值是乘积非线性目标；要用 MILP 需要特殊精确重构、分段线性化或下界。更重要的是，约束结构会使时间跨越多个数量级：Shin 等人的公开 MILP 实验中，添加干扰约束后，6/12 个目标的运行时间从 0.1/2.4 秒增至 3/超 8 小时；作者也明确说规模增大时运行时间不实用 [S3]。这不能直接推导本赛题的运行时间，但足以否定“只要交给 MILP 就稳定快”的假设。

## 建议的分档运行策略

### `20×50`

- 立即生成贪心可行解，作为 warm start 和超时保底。
- 运行 1-重定向、2-交换，直到局部无改进。
- 使用有时限的分支定界/MILP 或 VLSN；记录 incumbent、下界、gap、节点数和终止原因。
- 在离线验证中尽可能求到最优，用于评估快速层的质量；在线不依赖“必须证明最优”才能输出。

### `200×500`

- 使用矩阵化/堆加速的贪心构造，避免在 Python 中反复扫描所有已无效边。
- 对每个决策单元保留 top-k 候选目标，运行限时的 1-重定向、2-交换和 VLSN。`k` 是可反思调节参数，但必须记录其变化与收益。
- 只对少量“不确定边”开启 MILP/CP-SAT 小邻域；时限到立即返回当前最优可行解。
- 以预算分配而不是“收敛为止”控制运行：构造层、局邻域层、精确小邻域各有独立 deadline。

## 与反思演进的接口

反思控制器不应修改核心可行性检查或任意重写源码。适合暴露的有界操作是：

- 选择“贪心→局邻域”或“贪心→VLSN→精确小邻域”算法链。
- 调整 top-k、邻域大小、搜索次序、各层时间预算、风险惩罚和冗余上限，所有参数都必须有安全边界。
- 依据可观测信号切换：贪心后改进率、目标冲突密度、可行边稀疏度、求解器 gap 收缩速度、连续无改进轮数。
- 保留 best-so-far，新策略超时、不可行或未超过改进阈值时回滚。

这些操作都能产生“信号—操作—结果”日志，比不可解释的端到端分配更适合抽取**反思知识**。

## 验证要求与暂定门槛

下列是待实验验证的工程门槛，不是文献事实：

- 构造层对 `20×50` 的 p95 不超过 100 ms，对 `200×500` 的 p95 不超过 1 s。
- 完整基线的内部时限建议从 30 s 起测，并在官方环境明确后重新标定；不要用赛题的 10 分钟红线作常态预算。
- 同一输入、种子、线程数和时间预算下，报告相对贪心的改进、对已知最优/下界的 gap、p50/p95/p99 时延、失败率和可行性违反数。
- 小规模生成大量可求精确最优的实例，避免只在少数实例上比较。大规模使用多种稀疏度、概率分布、价值偏度和约束密度。
- 每个随机方法至少多种子重复；将“最好一次”与平均/最差分开报告。

## 仍需官方材料回答的问题

1. `p_ij` 是否为独立成功概率，评分目标是期望剩余价值、期望收益还是其他函数？
2. 一个决策单元可以分配几次，一个目标是否有覆盖下限/上限？
3. 是否存在时序、干扰、组合、射界或兼容性约束？
4. 质量分如何归一化，基线惩罚系数和每例运行时限是多少？
5. Docker 中可用 CPU/内存/线程数和允许的第三方求解器/开源许可边界是什么？

## 一手来源

- **[S1]** Ahuja, Kumar, Jha, Orlin, *Exact and Heuristic Algorithms for the Weapon-Target Assignment Problem*, Operations Research 55(6), 2007. [DOI](https://doi.org/10.1287/opre.1070.0440)。原文摘要给出问题定义、NP-complete 定性、网络流下界/构造、VLSN，以及 `80×80` 最优和 `200×200` 数秒内几乎最优的实验结论。
- **[S2]** Fisher, Nemhauser, Wolsey, *An analysis of approximations for maximizing submodular set functions—II*, 1978. [DOI](https://doi.org/10.1007/BFb0121195)。给出 matroid 约束下单调次模最大化贪心的经典近似结果；是否适用于最终赛题取决于官方约束。
- **[S3]** Shin, Lee, Choi, *Weapon-Target Assignment Problem with Interference Constraints using Mixed-Integer Linear Programming*, 2019. [arXiv 全文](https://arxiv.org/abs/1911.12567)。全文表 1 与结论报告加入干扰约束后的运行时间跨越。
- **[S4]** Madni, Andrecut, *Efficient Heuristic Approach to the Weapon-Target Assignment Problem*, Journal of Aerospace Computing, Information, and Communication 6(6), 2009. [DOI](https://doi.org/10.2514/1.34254)。原文摘要报告模拟退火和阈值接受在标准 PC 上数秒求解较大实例。
- **[S5]** SciPy, [`linear_sum_assignment`](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.linear_sum_assignment.html) 官方文档。说明该接口求线性和分配问题，用于限定该算法的适用边界。
- **[S6]** SciPy, [`milp`](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.milp.html) 官方文档。列出 `node_limit`、`time_limit`、`mip_rel_gap` 等可控终止选项。
- **[S7]** HiGHS, [官方文档](https://ergo-code.github.io/HiGHS/dev/)。说明 HiGHS 可求 LP/MILP，并提供 C++ 及多语言接口。
- **[S8]** Kline, Ahner, Hill, *The Weapon-Target Assignment Problem*, Computers & Operations Research 105, 2019. [DOI](https://doi.org/10.1016/j.cor.2018.10.015)。对静态/动态 WTA 的模型、精确和启发式方法进行综述，用于核对方法分类。

## 证据局限

- [S1] 的 `200×200` 是作者实验而非本赛题测试；不能将“数秒”直接承诺给 `200×500`。
- [S3] 研究的是带时间离散和干扰表的特定 MILP，只能证明约束结构对速度影响巨大，不能用来预测本题 MILP 的绝对时间。
- [S4] 的“近似最优”与“较大实例”来自原文摘要，在复现其实例和硬件前不作定量承诺。
- 官方 JSON Schema 和评分目标尚未核实，所以本文给出的是可适配的基线架构，不是最终求解器规格。
